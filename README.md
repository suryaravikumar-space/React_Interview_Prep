# React Interview Prep

A comprehensive React project for interview preparation and learning React concepts.

## Project Overview

This project includes a foundational React setup with:
- React 18.2.0
- React DOM integration
- CSS styling
- Example components and hooks
- Responsive design

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

### Running the Project

**Development Mode:**
```bash
npm start
```
Opens [http://localhost:3000](http://localhost:3000) in your browser.

**Build for Production:**
```bash
npm build
```

**Run Tests:**
```bash
npm test
```
